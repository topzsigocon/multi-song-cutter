SETUP BEFORE BUILDING THE APK
1. Download lame.min.js (lamejs 1.2.1) from:
   https://cdn.jsdelivr.net/npm/lamejs@1.2.1/lame.min.js
   and save it in this folder, next to index.html.
2. Upload this whole folder to an HTTPS host (GitHub Pages, Netlify, Cloudflare Pages).
3. Go to pwabuilder.com, enter your site URL, choose Android, and download the package.
4. Install the APK (enable "install unknown apps"). For Play Store you need the signed AAB.
